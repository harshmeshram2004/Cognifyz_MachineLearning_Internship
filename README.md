
# Cognifyz Machine Learning Internship

## Project Overview

This repository contains the machine learning tasks completed during the Cognifyz Technologies Internship Program.

## Tasks Completed

### Task 1: Predict Restaurant Ratings
- Preprocessed the dataset by handling missing values.
- Trained a regression model to predict restaurant ratings.
- Evaluated the model using R² Score and Mean Squared Error.

### Task 2: Restaurant Recommendation System
- Developed a recommendation system based on restaurant cuisines.
- Recommended similar restaurants using content-based filtering.

### Task 3: Cuisine Classification
- Built a classification model using Random Forest.
- Classified restaurants based on their cuisine category.
- Evaluated the model using Accuracy, Precision, Recall and F1-Score.

### Task 4: Location Based Analysis
- Analyzed restaurant distribution across different cities.
- Compared ratings and average cost of restaurants by location.
- Generated insights from geographical data.
